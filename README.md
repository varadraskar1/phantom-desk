# Phantom Desk

## Vision

Phantom Desk is a personal AI workspace designed to combine AI reasoning, tools, workflows, and automation into one modular platform.

The goal is not to create another chatbot.

The goal is to create a system that helps complete real-world tasks through:

- AI providers
- plugins
- workflows
- memory
- automation
- verification

## Current Status

Project initialization phase.

## Philosophy

- AI should reason.
- Plugins should execute.
- Deterministic tools should handle deterministic tasks.
- The system should be modular and replaceable.
