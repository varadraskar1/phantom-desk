# Phantom Desk Project Rules

## Development Principles

1. Modular first.
2. Document before major implementation.
3. Keep components replaceable.
4. Prefer deterministic tools over AI reasoning.
5. Avoid unnecessary complexity.
6. Maintain backward compatibility.

## AI Usage

AI should:

- Reason
- Plan
- Summarize
- Explain

AI should not replace:

- File systems
- Document generators
- Databases
- Security tools
- Deterministic software
